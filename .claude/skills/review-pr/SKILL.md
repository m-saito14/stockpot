現在の変更（または指定されたブランチ・PR）を 3 つの独立したレビュワーエージェントで並行レビューし、結果を統合してレポートを作成してください。

## 手順

### 1. レビュー対象の確認

```bash
git diff main...HEAD --stat        # 変更ファイル一覧
git log main...HEAD --oneline      # コミット一覧
```

変更の概要を把握する。

### 2. 3 エージェントを並行起動

以下の 3 エージェントを **同時に（単一メッセージで複数の Agent tool を呼び出して）** 起動する：

1. **code-reviewer** — 正確性・型安全性・**2 境界（LLM / ORM）とレイヤーの向き**・既存パターンとの一貫性
2. **security-reviewer** — Firebase 認証・認可（IDOR / 他ユーザー 404）・入力バリデーション・機密情報・LLM 課金
3. **test-reviewer** — コロケーション・カバレッジ・LLM 内容非テスト・認可 404・「書かないテスト」

各エージェントには「変更ファイルの差分を確認し、担当観点でレビューして問題点と推奨改善を報告せよ」と指示する。

### 3. レビュー結果の統合

3 エージェントの結果が揃ったら、以下の形式でレポートを作成する：

---

## PR レビューレポート

### 変更概要
（変更ファイル数・変更行数・目的の要約）

### コードレビュー結果 🔍
（code-reviewer の結果）

### セキュリティレビュー結果 🔒
（security-reviewer の結果）

### テストレビュー結果 ✅
（test-reviewer の結果）

### 総合判定
- **LGTM** / **要修正** / **要議論**

### 必須対応事項
（マージ前に必ず対応すべき項目。特に 2 境界違反・認可漏れ・課金リスクは必須）

### 推奨改善事項
（対応推奨だが必須ではない項目）

---

問題があれば具体的な修正案を提示し、ユーザーに確認を求めてから修正を進める。
